## Current research

**SilentEdge-LLM: Privacy-Preserving Silent Speech Recognition**

An in-progress research project for converting multi-channel sEMG signals into text locally on an edge device. The pipeline combines preprocessing, speaker verification, a lightweight EMG encoder, an EMG-to-LLM adapter, and quantized Llama 3.2 deployment on an NVIDIA Jetson AGX Xavier.
